# Typography (decided 2026-11-21)

- **Two fonts:** a friendly, round font for **headings** (the personality of the UPSC user's favourite design) and a font **designed for reading on screens** for lists, notes and topics (comfortable for hours). Exact fonts are chosen by trying real samples when the screens are designed.
- **Both must have a Devanagari version** (Hindi is a planned future language; changing fonts later would change the whole look), be **stored with the app** (works offline, faster, no third-party font servers), and be **variable fonts** where possible (one small file for all weights).
- **Sizes follow the phone's text-size setting** (relative units, never fixed); layouts must work at 200% text size.
- **Body text at least 16 px** at default settings.
- **A fixed type scale of about 6 sizes** (caption, body, subtitle, title, headline, display) as design tokens; themes can't add sizes.
- **At most 3 weights:** bold headings, regular body, one in between.
- **Comfortable reading:** body line height about 1.5×, lines of about 45–75 characters on wide screens.
- **Even-width numbers** for timers, streaks and stats, so changing digits don't make text jump.
- **Users choose fonts (later); designed for now:** fonts are **roles** in the token contract (heading, reading, numbers); nothing names a specific font, and the theme engine loads them, so swapping one is a setting. Later: a **font catalogue** of open-licence fonts as data-only font packs (including accessibility fonts such as Atkinson Hyperlegible and OpenDyslexic, tagged for reading), and **the user's own font file**, kept on that device only (never synced or shared, for licence reasons; browsers sanitise font files). Each role can be changed separately; automatic size and spacing adjustment plus fallbacks (missing letters, weights or Devanagari) keep layouts intact, checked in the playground.
- **An in-app text size setting (v0.1):** one slider in Settings, about **90% to 150%** in 5 steps, with a live preview, applied **on top of** the phone's text-size setting (for people who want bigger text only in Kiseki).
- **It works on every screen size:** everything is sized relative to text (no fixed heights); components adapt to their own space with container queries; important text wraps rather than being cut off; tap targets stay at least 48 px; the smallest text keeps a readable minimum. Layouts are guaranteed up to a **combined 200%** (WCAG: resize text and reflow), and beyond that still work by wrapping and scrolling. The playground checks every screen size × text sizes (90%, 100%, 150%, 200%) automatically.
