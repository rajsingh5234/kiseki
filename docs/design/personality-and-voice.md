# Personality and voice (decided 2026-11-21)

Kiseki is **a calm coach**. Every screen, message and animation is checked against this. UPSC and interview preparation are long and stressful; a calm personality is a deliberate counterweight, but calm never means vague.

## The three words

| Kiseki is                                                          | Kiseki is not                     |
| ------------------------------------------------------------------ | --------------------------------- |
| **Calm:** short, unhurried, never alarmist                         | Cold or robotic                   |
| **Encouraging:** notices effort and progress                       | Preachy or childish               |
| **Honest:** says clearly where the user stands, with a way forward | Vague, or only saying nice things |

## How the tone shifts with the moment

| Moment              | Example                                                                                                | Rule                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| Everyday            | "Polity at 5:30. Two items, about an hour."                                                            | Short and factual                                |
| Something done      | "Done. Polity ch. 6 is in your revision plan."                                                         | A quiet confirmation                             |
| An earned milestone | "30 days in a row. That's real consistency 🌱"                                                         | Warm; the only place for an emoji or playfulness |
| A missed day        | "Yesterday's work is spread over the next few days. You're still on track."                            | No guilt: what happened and what's next          |
| Behind schedule     | "At this pace you finish 2 weeks after Prelims. Add 30 minutes a day, or focus on high-weight topics?" | Clear numbers and options                        |
| An error            | "We couldn't save that. Check your connection and try again."                                          | Plain; we own the problem, never blame the user  |

## Writing rules

1. **Plain words, short sentences**, talking to "you".
2. **Concrete numbers**, not vague praise ("2 weeks behind", not "a bit behind").
3. **Always a next step** when something isn't right.
4. **No shaming words:** never "failed", "lazy", "only 2 hours", "you missed".
5. **Celebration is rare and earned:** exclamation marks, emojis and playful touches only for real milestones (the whole day's plan done, streak milestones), never for ticking a single item. Used everywhere, they make the real ones meaningless.
6. **No slang or idioms**, so text translates well (Hindi is a planned future language).
7. **Greet by first name**, warmly but briefly ("Good morning, Asha"), with no forced enthusiasm.
