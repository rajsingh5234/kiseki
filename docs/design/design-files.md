# Design files

Where Kiseki's screen designs live. Add a line here whenever a new design file is made.

| File                                                                                   | What it holds                                                                                                                                                                                                        | How to use it                                                                                |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [All screens (design canvas)](https://claude.ai/artifact/NCpckrVSrxtNhVVmB2vWE1)       | Every screen design on one board, like Figma: Today (the flat bar, which is the default, and the cradle bar, light and dark; flat, clay and glass) the finishing-an-item flow, and welcome and sign-in at every size | Zoom out to see all the screens at once; zoom in on one. Screens are pictures, not clickable |
| [Finish flow (clickable prototype)](https://claude.ai/artifact/2ohr7hr2GicPfLgRZGoxTP) | A working Today screen: tick an item, answer, part done, note, Undo, edit; switch flat / clay / glass, flat bar / cradle and light / dark; reduce motion                                                             | Open on a phone to feel the motion and thumb reach. Throwaway prototype code, not the app    |
| [Welcome motion (prototype)](https://claude.ai/artifact/LFSD68gXbx9khi89ukveJr)        | The welcome screen's motion: books stack in with springs, sparkles appear and twinkle, tap the books; replay, slow motion, reduce motion                                                                             | Feel the first-time animation. Throwaway prototype code, not the app                         |

- **Access:** the design canvas is private (shared from its Share menu when needed); the prototype is shared with anyone who has the link.
- **Source:** the designs live in these files themselves (their history keeps every version); the app's real code is built from them at the build steps.
